02 / CHROME

安装独立实验扩展

  1. 打开 chrome://extensions 并开启开发者模式。
  2. 选择「加载已解压的扩展程序」，使用下面的目录。
  3. 把「Resume Agent Lab · 模型自主决策」固定到工具栏。

扩展有独立 ID 和资料库。在扩展的「编辑资料」中填表，或导入已有插件导出的资料备份。
