# Independent Resume Agent Lab

- Work only in this project for the Agent migration. `../RESUME_AGENT` is the frozen, usable plugin baseline; `../RESUME_FILL_MAC` is its distribution project. Do not edit either, or any project in FORMFILL_RESEARCH.
- Real execution must enter through the normal Chrome toolbar Start button. Use the selected tab's original document for the entire task; switching focus must not redirect it.
- The model chooses the next tool from an explicit registry. Never silently substitute the original fixed filling runner or a scripted test policy for a failed model call.
- No tool may submit, apply, register, save, sign, accept a declaration, navigate, run arbitrary code, or click an arbitrary element. Ordinary user page controls and network requests remain available.
- Use fictional profiles for development. Keep API keys and profile values out of source, logs, traces, checkpoints and reports. Values stay in the Chrome profile ledger and only enter the selected field executor.
- Validate model actions, source evidence, document identity and tool results. Reobserve before acting after model latency; invalidate plans on structural changes. Report unsupported or missing fields explicitly.
- Explain each migration milestone in Chinese, with its place in the architecture and primary references. State test scope accurately; a fake model test does not prove LLM behavior, and DOM readback does not prove a recruitment server accepted a resume.
- Do not use subagents unless the user explicitly asks for them.
