# Chrome 真实页面启动与通用控件修复

日期：2026-10-07。项目：`RESUME_AGENT_LAB`。扩展及服务版本：0.1.4。

## 验证入口和范围

招聘页面为 `https://smics.zhiye.com` 的简历个人信息页。每次真实填写从 Chrome 中 **Resume Agent Lab → 开始填写此标签页** 进入，使用用户现有模型和资料库，保持默认覆盖模式。没有为验收修改 API、资料、日期补全设置，也没有直接给页面预填测试答案。

开发者工具只用于读取文档状态、页面自身错误和下拉菜单公开选项。没有保存私人页面截图、实际资料值、API 密钥或原始模型响应。没有点击保存、下一步、预览或提交。

## 1. 原始“开始后没反应”的原因

- 扩展显示运行中，但执行事件为 0，本地服务活动任务为 0。
- 补充启动阶段日志后，实际复现 `REAL_DOCUMENT_BIND_TIMEOUT`，模型尚未收到任务。
- 该页面主文档请求显示 `ERR_INCOMPLETE_CHUNKED_ENCODING`；文档状态长期为 `loading`，但表单 DOM 已出现。
- Chrome 脚本注入默认等待 `document_idle`，使旧入口一直等待网页结束加载。

修复：绑定、扫描及实际工具注入使用 `injectImmediately: true`，保留原文档身份校验和执行前重新观察。启动新增文档绑定、服务连接、首次响应的独立日志与超时；停止能取消等待，晚到的回调不能重启旧任务。

参考：[Chrome 官方 scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)。

## 2. 启动后观察到的通用问题与修复

| 日志或页面证据 | 修复 |
| --- | --- |
| 单选的两个选项被当成两个字段，同一性别或色觉资料重复引用 | 同一表单所有者、名称、问题和记录的原生单选合并成一个逻辑字段；实际选项绑定仍在本地 |
| 原生单选的相邻 `label` 没有 `for`，选项标题缺失或与问题标题混淆 | 分开读取问题标题和选项标题，并在执行时校验选项身份 |
| 最新教育的学习形式投影被判定不兼容 | 接受有合法教育来源证据的对应投影，仍拒绝不同属性或无来源投影 |
| 格式错误的诊断未进入下一轮模型决策 | 传回受控的格式诊断与此前规划失败；执行面板显示分组进度和校验依据 |
| 不同规划错误连续出现也触发重复动作停止 | 同时比较动作参数和结果诊断；相同错误循环仍受保护 |
| 模型把个人简介借给不相关的补充问题 | 简介只用于个人介绍类字段，其他题需要独立资料或对应自定义答案 |
| “信息渠道”有学校就业网的中英双语选项，但匹配返回 `OPTION_UNAVAILABLE` | 支持学校就业网的明确双语翻译及 BBS 附注，仍拒绝歧义或不相关渠道 |
| 工具失败后模型误说菜单没有选项 | 保留选项数量和控件适配器诊断，区分匹配失败与没有选项 |

修改没有添加中芯国际专用字段路径或公司名称判断。下一项填写、重试、重新规划、复核、暂停仍由真实模型选择，没有切换为固定填写程序。

## 3. 中间版本的实际结果

- 0.1.1 修复立即注入后的实际运行：核验写入 13 项，仍有 22 个可见文本空白，最终触发重复规划停止。
- 0.1.2 的实际复测：启动成功，但三次不同的重复引用错误使整份计划被拒绝；新增写入 0 项。
- 0.1.3：观察 55 个逻辑字段、2 个分组；尝试写入 19 次，控件回读核验 17 项。信息渠道两次匹配失败，模型请求人工核对，暂停时还有 5 项已映射候选及 29 项未规划字段。该轮没有完成最终审计。

69 个原始字段减少到 55 个逻辑字段，原因是合并 14 组单选选项，并非删除问题或隐藏遗漏。上述轮次共享同一个未刷新的招聘文档，默认覆盖模式会再次核验已有内容；数量不能相加为新填字段总数。
