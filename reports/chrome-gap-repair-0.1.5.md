## 核对方式

- 通过 Chrome UI 查看用户原页面和 Lab 扩展本轮执行记录。
- 资料编辑器只读核对字段是否有值、日期保存精度；不将私有值写入文件或服务日志。
- 公共选项与组件结构用于诊断。公开加载的组件脚本用于确认网站选择器协议。
- 实测每次从普通工具栏“开始填写此标签页”进入，使用现有模型、现有资料、默认全部覆盖和原日期开关；没有设置测试专用答案。
- 本轮没有刷新目标页、保存简历、点击下一步、预览或提交。

## Agent 与工具基础设施变化

- 新增 `inspect_field` 工具。真实模型可选择它观察可公开选项和组件 API 就绪情况，再选择下一步。
- `fieldCoverage` 提供逐项证据分类，扩展增加“查看未填写原因”和“补充本页缺失资料”。没有合法映射时不直接宣称资料缺失。
- `request_review` 暂停期间可以保存资料。恢复使用 LangGraph `Command`，发现资料随机版本标识改变后重新观察和规划；原网页内容保留。
- 最初的失败诊断不会因为后续空白复扫或审计而被改写为写入丢失。
- 基本信息摘要页不会因为模型声明了多个经历资料区块而产生虚假的待添加卡片数。
- 所有动作继续由模型选择；没有按公司编排固定顺序或回退旧插件的填写循环。

## 真实调试中途结果

第一次更新后的工具栏实测暂停时核验 15 项，存在 3 项执行失败，模型仍遗漏地址、出生日期和籍贯。它确实调用了 `inspect_field`，读到网页公开选项；这份失败证据推动了后续候选约束、别名与失败原因保留修复。该次不是成功验收。

最后一次锁屏前的真实工具栏执行：`742e1a1a-c2f6-4adf-a319-1673bac84507`，状态 `waiting_review`。20 项本轮写入在整页复核中保持，55 个观察字段中仍有 31 个可见空白，2 个执行未完成；没有添加虚假的经历卡片，审计为当前版本。地址、出生日期、英语等级和学习形式均有成功回读。这个结果不是全页完成或业务保存成功。

未完成的两项为籍贯 `DICTIONARY_NOT_LOADED` 和毕业日期 `DATE_PRECISION_INCOMPATIBLE`。色觉问题已有页面选择但缺少本轮收据，不能算本轮核验成功。另发现亲属任职题被规划为 `personal.firstName`，以及未注明周期的期望薪资被规划为年薪；两种映射都需要排除，不能算资料配置正确。

锁屏期间已在源码中补上亲属任职来源限制、年薪独立配置及周期约束、工作意愿的成对选项转换。空白地区弹窗现在先绑定本轮所有权，失败后只取消自己打开的弹窗。地区加载诊断增加设置、地区、拼音三个阶段的观察标记和请求数，不保存请求 URL、租户 ID 或答案。

**这些最后补充已构建并通过自动检查，但尚未在 Chrome 中重新加载验收。** 工具报告 Mac 锁屏且无法自动解锁，已请求用户解锁。地区字典根因仍需浏览器中的实际加载证据，不能据现有超时推断网络原因，也不能把虚构 DOM 的成功当成该网站成功。
