# Agent Lab 路线图

每个里程碑包含代码、证据和一篇中文技术讲解。可用插件基线继续保留。

| 阶段 | 内容 | 验收标准 |
| --- | --- | --- |
| M0 已完成 | 独立目录、工具快照和基线校验 | 原 206 文件 SHA-256 一致，资料与 API 未复制 |
| M1 已实现 | LangGraph、模型选工具、反馈、内存检查点与人工暂停 | 脚本模型能采用不同动作序列；真实模型能选择填写、恢复和扩展；非法工具不执行 |
| M1 Chrome 验收待完成 | 正常 Chrome 工具栏链路 | 只点击开始；刷新后首轮稳定；页面状态接收输入；切换标签页不转移任务 |
| M2 部分已实现 | 控件观察、具体错误反馈、结构化任务记忆、补资料后恢复 | 已加入模型可选检查工具、来源约束与逐字段覆盖证据；真实地区控件和跨页面布局的验收仍待完成 |
| M3 | SQLite 检查点和任务恢复协议 | 重启后重新绑定并观察；不把旧动作直接重放；敏感值不入检查点 |
| M4 | 全过程评估和上下文优化 | 可复现真实模型轨迹；区分显示、页面状态和业务接受；衡量成本与覆盖 |
| M5 | 视觉观察与可验证的动作批次 | DOM 证据不足时可定位；批次遇到页面变化时立即作废后续动作 |

加入框架是实现手段。每阶段验收的是具体行为和证据，不以依赖列表作为完成条件。
